# Student Result Management System

## Project Overview
The Student Result Management System is a console-based Java application developed to manage student information and academic results. It allows users to add, view, search, delete, and sort student records through a simple menu-driven interface.

The application also calculates grades automatically based on students' marks and validates user inputs to maintain accurate records.

## Project Objectives
- To understand Java programming concepts.
- To implement Object-Oriented Programming (OOP).
- To manage student records using ArrayList.
- To perform basic CRUD operations.
- To implement sorting and searching.
- To handle invalid inputs using exception handling.

## Features
1. **Add Student:** Enter student name, ID, and marks.
2. **View Students:** Display all available student records.
3. **Search Student:** Find a student using their unique ID.
4. **Delete Student:** Remove a student record using their ID.
5. **Sort Students:** Arrange student records in descending order of marks.
6. **Automatic Grade Calculation:** Calculate grades based on marks.
7. **Input Validation:** Check student names, IDs, duplicate IDs, and marks.
8. **Exception Handling:** Handle invalid numerical inputs and prevent unexpected program termination.

## How to Run the Project

### Prerequisites
- Java Development Kit (JDK)
- Visual Studio Code or any Java-supported IDE

### Execution Steps

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project directory.
4. Compile the Java files using:

   javac Student.java Main.java

5. Run the application using:

   java Main

6. Follow the menu displayed in the terminal to manage student records.
